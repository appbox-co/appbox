# За документацију

1. Направите нову `.mdx` датотеку у фасцикли одељка унутар `apps/content/docs/en`, на пример `apps/content/docs/en/apps/jellyfin.mdx`.
2. Додајте frontmatter описан у наставку, а затим напишите страницу.

Бочна трака и command palette за претрагу генеришу се из датотека на енглеском помоћу `apps/web/src/config/docs.ts`. Свака фасцикла постаје одељак, а свака датотека страница у њему, тако да се нова датотека појављује без икаквих измена у конфигурацији. Нова фасцикла додаје нови одељак, па о њој прво разговарајте у issue-у.

Нове странице пишите само на енглеском. На страници [Писање документације](/docs/contributing/writing-docs) пронаћи ћете где се странице постављају, шаблон странице апликације и водич за стил.

## Подешавања MDX документа

MDX документи се чувају у фасциклама `apps/content/docs/[language]` и `apps/content/blog/[language]`. Сваки документ је MDX датотека која садржи заглавље са metadata подацима, као што су наслов и опис. Испод је пример заглавља документа:

```mdx
---
title: Document Title
description: Document Description.
sort: 1
---
```

Подржана су следећа metadata поља:

- `title` (обавезно): Наслов документа.
- `description` (обавезно): Кратак опис документа.
- `sort` (опционо): Број који одређује редослед документа у његовом одељку. Документи са вредношћу `sort` иду први, од најниже ка највишој. Иза њих следе документи без те вредности, сортирани абецедно по наслову.
- `links` (опционо): Линкови ка повезаним документима, API референцама, изворном коду итд.
- `toc` (опционо): Да ли да се прикаже садржај. Подразумевано је `true`.

Да бисте додали нове metadata податке у документ, можете додати нове кључеве у заглавље. На пример, можете додати кључ `author` да означите аутора документа:

```mdx
---
title: Document Title
description: Document Description.
sort: 2
author: Author Name
---
```

Али када додајете прилагођене metadata податке, такође морате да додате поље у одговарајућу шему (`docSchema`, `blogSchema` или `policySchema`) у `apps/web/src/lib/content/index.ts`. Frontmatter кључеви којих нема у шеми се одбацују.
Након тога, мораћете да прикажете нове информације у шаблону документа. Да бисте то урадили, ажурирајте датотеку `apps/web/src/app/[locale]/(marketing)/docs/[[...slug]]/page.tsx`, или `apps/web/src/app/[locale]/(marketing)/blog/[[...slug]]/page.tsx`, или неку од њених подкомпоненти.

## Провера измена

Сајт директно чита MDX датотеке, па `pnpm dev` приказује измене када освежите страницу. Ако frontmatter неке датотеке није исправан, `pnpm dev` изоставља ту страницу и у терминалу исписује датотеку и поље. `pnpm build` проверава сваку датотеку на сваком језику и завршава се грешком ако је било која од њих неисправна.
