# 用于文档

1. 在 `apps/content/docs/en` 下的某个栏目文件夹中创建新的 `.mdx` 文件，例如 `apps/content/docs/en/apps/jellyfin.mdx`。
2. 添加下文所述的 frontmatter，然后编写页面。

侧边栏和搜索命令面板由 `apps/web/src/config/docs.ts` 根据英文文件生成。每个文件夹会成为一个栏目，其中的每个文件会成为该栏目下的一个页面，因此新文件无需任何配置更改即可显示。新建文件夹会增加一个新栏目，因此请先在 issue 中讨论。

新页面只用英文编写。关于页面应放在哪里、应用页面模板和风格指南，请参阅[编写文档](/docs/contributing/writing-docs)。

## MDX 文档设置

MDX 文档存储在 `apps/content/docs/[language]` 和 `apps/content/blog/[language]` 文件夹中。每个文档都是一个 MDX 文件，文件头包含元数据，例如标题和描述。下面是一个文档头示例：

```mdx
---
title: Document Title
description: Document Description.
sort: 1
---
```

支持以下元数据字段：

- `title`（必填）：文档标题。
- `description`（必填）：文档的简短描述。
- `sort`（可选）：决定文档在所属栏目中顺序的数字。设置了 `sort` 值的文档排在前面，值越小越靠前。未设置该值的文档排在其后，按标题字母顺序排序。
- `links`（可选）：指向相关文档、API 参考、源代码等的链接。
- `toc`（可选）：是否显示目录。默认为 `true`。

要向文档添加新的元数据，可以在文件头中添加新键。例如，你可以添加 `author` 键来表示文档作者：

```mdx
---
title: Document Title
description: Document Description.
sort: 2
author: Author Name
---
```

但添加自定义元数据时，还需要在 `apps/web/src/lib/content/index.ts` 中把该字段添加到对应的 schema（`docSchema`、`blogSchema` 或 `policySchema`）。不在 schema 中的 frontmatter 键会被丢弃。
之后，你需要在文档模板中显示新信息。为此，需要更新 `apps/web/src/app/[locale]/(marketing)/docs/[[...slug]]/page.tsx` 文件，或 `apps/web/src/app/[locale]/(marketing)/blog/[[...slug]]/page.tsx`，或其中的某个子组件。

## 检查你的更改

站点直接读取 MDX 文件，因此刷新页面后 `pnpm dev` 就会显示更改。如果某个文件的 frontmatter 无效，`pnpm dev` 会跳过该页面，并在终端中输出对应的文件和字段。`pnpm build` 会检查所有语言中的每个文件，只要有任何文件无效就会失败。
